# Clinical Note Accuracy & Verification Engine
**ICT942 - Cyber Security Project (Assessment 1)**

## Project Overview
This repository contains the design, analysis, and future source code for a Clinical Note Verification Engine built for FAZ Australia. The tool acts as a safety net to automatically compare AI-generated clinical notes against consultation transcripts to flag omissions, contradictions, and hallucinations.

2. Commit your changes regularly with clear, descriptive messages.
3. Open a Pull Request (PR) against the `main` branch.
4. Require at least one peer review before merging.
